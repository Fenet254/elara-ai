# Daily Budget Tracker

## Category
Full Stack Web Development / FinTech

## Summary
A MERN stack application for tracking daily income, expenses, and budgets, with support for manual entry and automatic SMS/Telebirr/CBE Birr transaction imports.

## Problem It Solves
Personal finance tracking is tedious when done manually. This app addresses that specifically for Ethiopian users by automating transaction capture from common local payment platforms (Telebirr, CBE Birr) via SMS parsing, alongside manual entry.

## Architecture / How It Works
Built on the MERN stack (MongoDB, Express, React, Node.js). Includes secure login/authentication, budget monitoring logic, and transaction management. SMS parsing logic extracts transaction data automatically from Telebirr/CBE Birr notification messages.

## Technologies Used
JavaScript, MongoDB, Express.js, React, Node.js

## Key Features
- Manual and automatic (SMS-based) transaction entry
- Telebirr and CBE Birr import support
- Secure user authentication
- Budget monitoring and transaction management dashboard
